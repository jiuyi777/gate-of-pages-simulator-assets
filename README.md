# 万页之门 · 故事模拟器远程素材

这是“万页之门·故事模拟器”URL 版角色卡使用的公开静态素材仓库。

## 给玩家

1. 下载发布者提供的 `万页之门-故事模拟器-URL版.card.png`。
2. 在 SillyTavern 角色管理中导入角色卡。
3. 开启角色卡自带的正则脚本并新建对话。
4. URL 版需要联网读取本仓库中的图片；故事存档仍保存在玩家自己的浏览器中。

## URL 版与离线版

- URL 版：角色卡体积小，图片从 GitHub CDN 按需加载。
- 离线版：图片全部内嵌，文件较大，但断网仍能完整显示。
- 两版使用相同的世界、Prompt、世界书与存档结构，可以同时保留。

## 隐私

本仓库只包含界面图片和 SVG。它不包含 API Key、模型设置、聊天记录、故事存档或玩家填写的内容。

## 更新说明

角色卡引用带版本号的 CDN 地址。素材更新时应发布新版本并重新构建 URL 版角色卡，避免旧卡在缓存中突然改变。
